Finding Nemo V5 — proposed insulator audit
Decision rules (magenta = proposed box; other colours = existing labels)
  • Accept — a real, healthy insulator string that is not already labelled, and the box fits it tightly (within ~10% on each side).
  • Reject — not an insulator, already covered by an existing box, a defect that should be another class, or too occluded/blurred to label by the dataset convention.
  • Adjust — a real unlabelled insulator but the box is clearly too loose/tight or covers two strings; describe the fix in Notes.
  • Unsure — cannot decide; explain why. Unsure items are excluded from the frozen set unless resolved.
Decisions are saved in this browser only. Export review.csv when finished (and from time to time as a backup).
